# قواعد المحاسبة والترحيل

## سياسة الإصدار الأول
- شركة واحدة، أساس الاستحقاق، العملة الوظيفية SAR.
- القيد المزدوج هو المصدر المحاسبي الرسمي.
- تحفظ المبالغ في قاعدة البيانات بدقة منزلتين عشريتين، وفي منطق TypeScript بوحدات العملة الصغرى الصحيحة لتجنب أخطاء الكسور العشرية.

## حالات القيد
1. **مسودة:** قابلة للتحرير، ولا تدخل في القوائم المالية.
2. **مرحّل:** اجتاز التحقق، ويظهر في الأستاذ العام وميزان المراجعة والقوائم المالية.
3. **معكوس:** لا يحذف أثر القيد الأصلي؛ تتم المعالجة بقيد عكسي مرتبط به.

## شروط الترحيل
- سطران على الأقل.
- حسابات نشطة وتقبل الترحيل وليست حسابات تجميعية.
- كل سطر مدين أو دائن فقط وبمبلغ موجب.
- إجمالي المدين يساوي إجمالي الدائن.
- تاريخ القيد داخل فترة مالية مفتوحة.
- لا يسمح بتعديل أو حذف سطور القيد بعد ترحيله.

## ملاحظات ما قبل الإنتاج
هذه هي بنية قاعدة البيانات الأولى وقواعد المجال، وليست بعدُ نظاماً مكتملاً. يلزم استكمال المصادقة وربط قاعدة PostgreSQL وواجهات API والصلاحيات واختبارات التكامل والنسخ الاحتياطي، ثم مراجعة محاسب مختص قبل اعتمادها في العمل الفعلي.

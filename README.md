# نظام الشموخ ERP

نظام محاسبي احترافي باللغة العربية والإنجليزية، مخصص لشركة واحدة في الإصدار الأول، ومبني على أساس الاستحقاق والقيد المزدوج، مع الريال السعودي (SAR) عملةً أساسية.

## أهداف المشروع
- دفتر يومية مع التحقق من توازن القيود قبل الترحيل.
- دليل حسابات هرمي، دفتر أستاذ عام، وميزان مراجعة.
- القوائم المالية: الدخل، المركز المالي، والتدفقات النقدية.
- العملاء والموردون والصندوق والبنوك والمبيعات والمشتريات والمخزون.
- صلاحيات المستخدمين وسجل التدقيق وإقفال الفترات.
- دعم العربية RTL والإنجليزية LTR وتصميم متجاوب.

## الإعدادات المعتمدة
- نطاق الإصدار الأول: شركة واحدة.
- الأساس المحاسبي: الاستحقاق.
- العملة الأساسية: SAR.
- منهج التسجيل: القيد المزدوج.
- التقنية المستهدفة: Next.js وTypeScript وPostgreSQL.

## قواعد محاسبية أساسية
- كل مستند مالي مرحّل ينشئ قيداً محاسبياً متوازناً.
- مجموع المدين يساوي مجموع الدائن.
- التقارير تعتمد على القيود المرحلة فقط.
- لا تعدّل القيود المرحلة مباشرة؛ استخدم قيد عكس أو تسوية وفق الصلاحيات.

## خارطة الطريق
1. تأسيس المشروع والمستخدمين والصلاحيات.
2. دليل الحسابات والفترات المالية.
3. دفتر اليومية والترحيل والعكس والمرفقات.
4. الأستاذ العام وميزان المراجعة والقوائم المالية.
5. العملاء والموردون والصندوق والبنوك.
6. المبيعات والمشتريات والمخزون والأصول.
7. ضريبة القيمة المضافة والفوترة الإلكترونية السعودية ومتطلبات ZATCA.
8. الاختبارات والأمان والنسخ الاحتياطي والنشر.

> هذا المستودع نقطة انطلاق للمشروع، وليس نظاماً معتمداً أو جاهزاً للإنتاج قبل استكمال التطوير والاختبارات والتحقق من المتطلبات النظامية.

# إعداد الشركة ودليل الحسابات

بعد تطبيق الترحيلين 0001 و0002، أنشئ الشركة والفترة المالية ثم أضف دليل الحسابات الافتراضي:

```sql
select initialize_company(
  'الاسم القانوني للمنشأة',
  'اسم المنشأة المعروض',
  date '2026-01-01',
  date '2026-12-31'
) as company_id;
```

انسخ قيمة `company_id` الناتجة ثم نفّذ:

```sql
select seed_default_chart_of_accounts('ضع-company-uuid-هنا');
```

هذه البيانات نقطة بداية قابلة للتعديل قبل تسجيل الأرصدة الافتتاحية. راجع أسماء الحسابات وترميزها مع دليل الحسابات المعتمد لدى المنشأة والمحاسب المسؤول.

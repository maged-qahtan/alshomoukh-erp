# قاعدة البيانات والتقارير

## تشغيل الترحيلات
نفّذ ملفات SQL بالترتيب على قاعدة PostgreSQL جديدة:
1. `database/migrations/0001_initial.sql`
2. `database/migrations/0002_reporting_and_reversal.sql`
3. `database/migrations/0003_company_setup_and_chart.sql`

## وظائف محاسبية
- `post_journal_entry(entry_id, user_id)`: يتحقق من الفترة المالية وتوازن القيد وصلاحية الحسابات ثم يرحّله.
- `reverse_journal_entry(entry_id, reversal_date, fiscal_period_id, user_id)`: ينشئ قيداً عكسياً متوازناً، يرحّله، ويربطه بالقيد الأصلي.
- `general_ledger`: دفتر الأستاذ مع الرصيد الجاري لكل حساب.
- `trial_balance`: مجاميع وأرصدة المدين والدائن.
- `income_statement_accounts`: أرصدة حسابات الإيرادات والمصروفات.

القيد الأصلي المعكوس لا يُحذف من الأستاذ؛ يظهر مع قيده العكسي حتى يكون صافي الأثر صفراً. هذه التقارير مبنية على القيود المرحلة والمعكوسة فقط، ولا تشمل المسودات.

> يجب اختبار الترحيلات والوظائف على قاعدة تجريبية قبل تشغيلها في بيئة إنتاج.

بعد تطبيق الترحيلات الثلاثة، استخدم تعليمات `database/seeds/README.md` لإنشاء الشركة والفترة المالية ودليل الحسابات الأولي.
